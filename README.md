## 🚀 Quick Start / Local Preview

Because the website is built with modern HTML5, Tailwind CSS, and vanilla JavaScript without heavy build pipelines, you can run it instantly:

### Option 1: Direct Browser
Simply double-click `index.html` or open it directly in any modern browser (Chrome, Edge, Safari, Firefox).

### Option 2: Local HTTP Server (PowerShell / Python / Node)
If you prefer running a local server:
```powershell
# Using Python
python -m http.server 8000

# Or using npx
npx serve .
```
Then visit `http://localhost:8000`.

## 🌐 Deploying to GitHub Pages

1. Push this repository to your GitHub account:
   ```bash
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**
   - Branch: `main` / folder: `/ (root)`
   - Click **Save**
3. Your website will be live in 1-2 minutes at:
   `https://<your-username>.github.io/<repo-name>/`
